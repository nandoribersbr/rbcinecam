# RB CineCam 0.9 Alpha Monitoring Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add real production monitoring and reliable media navigation to RB CineCam 0.9 Alpha.

**Architecture:** Bind CameraX ImageAnalysis alongside existing preview/capture use cases and compute immutable RGB histogram/luma waveform frames off the UI thread. Keep AudioLevelMonitor as the real PCM source but move its UI to a dedicated always-visible strip. Upgrade gallery/player navigation without changing the capture storage format.

**Tech Stack:** Kotlin, Jetpack Compose, CameraX 1.6.2, Camera2 Interop, ImageAnalysis, MediaStore, Media3 ExoPlayer.

**Spec:** `docs/superpowers/specs/2026-09-09-rbcinecam-0.9-monitoring-design.md`

## Global Constraints
- No decorative/fake controls.
- Scopes and meters are monitoring-only and never burned into recorded media.
- Preserve working REC, photo, focus, manual controls, gallery/player and grid behavior.
- Preserve stable alpha signing.
- Landscape-first UI.
