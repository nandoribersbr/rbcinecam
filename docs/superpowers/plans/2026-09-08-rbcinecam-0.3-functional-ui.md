# RB CineCam 0.3 Functional UI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver a landscape RB CineCam interface where every visible control executes real camera or media behavior.

**Architecture:** Keep CameraX for preview, video and photo capture, and use Camera2 interop only for manual sensor controls. UI remains Compose and exposes only implemented controls.

**Tech Stack:** Android/Kotlin, Jetpack Compose, CameraX 1.6.2, Camera2 Interop, MediaStore.

**Spec:** `docs/superpowers/specs/2026-09-03-rbcinecam-android-design.md`

## Global Constraints

- No decorative/dead buttons.
- Landscape-first UI.
- Visible manual controls must affect the active camera.
- Unsupported controls must be disabled or omitted.
- Video recording and still photo capture must save into MediaStore.

---

### Task 1: Functional camera controller
- Add real ImageCapture, gallery URI support, Camera2 manual ISO/shutter/WB/focus, EV, and camera switching.
- Expose current control state to the UI.
- Verify compilation and unit tests.

### Task 2: Professional landscape UI
- Replace the portrait HUD with a landscape layout inspired by the approved mockup.
- Bind every visible control to the controller.
- Keep only functional actions: video, photo, gallery, switch camera, ISO, shutter, WB, focus, EV.
- Verify compilation.

### Task 3: Version and build
- Bump to 0.3.0-alpha / versionCode 3.
- Force sensor landscape orientation.
- Rename Actions artifact to RB-CineCam-0.3-Alpha-APK.
- Run tests and assembleDebug in GitHub Actions.
- Download only a successful artifact and deliver the APK.
