# RB CineCam 0.15 Audit and Functional Controls Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make capture settings reflect and apply real camera state, remove build-time patch fragility, and refine the full-screen translucent camera UI.

**Architecture:** Consolidate the effective 0.14 patched camera engine and UI into source-of-truth Kotlin files. Introduce explicit capture state/capability modeling and transactional camera reconfiguration so the UI only changes after a successful bind. Keep unsupported combinations visible only when they can be safely rejected or adjusted.

**Tech Stack:** Android/Kotlin, Jetpack Compose, CameraX 1.6.2, Camera2 Interop, JUnit, GitHub Actions.

**Spec:** Approved in conversation: full-screen preview, compact translucent controls, every visible control functional, safe quality/FPS reconfiguration, comprehensive app audit.

## Global Constraints
- Android focus.
- CameraX + Camera2 Interop.
- Never crash when changing quality/FPS.
- UI state must represent successfully applied camera state.
- Aspect ratio remains monitor framing unless encoded crop is explicitly implemented.
- Preserve recording, photo, focus, audio meter, scopes, gallery and stable alpha signing.
